# B2B 汽配出海项目调研文档库

解决方案提供商视角下的 B2B 汽配交易系统可行性调研文档集。核心问题：**卖系统（不做配件生意），卖什么、卖给谁、能卖几套、从哪切入**。

- 调研时间：2026 年 10 月
- 方法：公开网络信息检索（中/俄/英），证据分级标注
- 视角：解决方案提供商（详见《[委托方构想](docs/委托方构想-解决方案商视角.md)》）
