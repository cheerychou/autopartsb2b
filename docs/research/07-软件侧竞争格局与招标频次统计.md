# 软件侧竞争格局与招标频次统计

> 时间：2026-10-24 ｜ 性质：承接信息收集计划第4、5项（对应 [05号报告](05-四线索验证报告-潜在客户与可售基数.md) 行动清单）
> 视角：解决方案商——回答"卖系统这门生意的竞争者是谁、能卖几套、卖多少钱"
> 证据分级：✅ 原文核实 ｜ ◻️ 检索摘要 ｜ ⚠️ 未证实/已证伪

## 一、结论摘要

1. **车企海外DMS赛道已非空白**：联友科技（东风系DMS大厂）2026年7月发布"海外DMS助力车企出海"专项方案（✅官网全文），覆盖线索、整车、售后、**备件**四大业务域；用友汽车（DMS龙头）、东软（商用车软件35年）在位。**正面战场（给车企做通用海外DMS）不可入**。
2. **三个结构性空位仍在**：①配件适配目录数据（联友DMS的备件模块管流程，仍依赖OEM自己的主数据/EPC——无人解决"多品牌中国商用车件适配"）；②**汽配商客群**（联友/用友只做主机厂，不做汽配商——B线客群无直接竞争）；③轻量性价比段（小众车企买不动大厂DMS，大厂也不愿做几百万级小单）。
3. **招标频次**：2024–2026公开可查的车企"海外营销/配件系统"类采购约**8起/2年**；考虑大量邀标/比选不挂网（福田用的就是半公开"比选采购"），估算真实市场**8~12起/年**。对新进入者，现实可得约**1~3起/年**（小众车企+跟随份额）。
4. **"3~5套"结论**：C线单段无法保证，需 **C（车企项目，200万+/个）+ B（出海汽配商，数万~数十万/套）** 两段凑数；A线仅作案例来源。
5. ⚠️ 证伪与澄清：重汽"全域车辆管理服务平台"（2026-10招标）是车辆动态监控/时空信息类项目，**非**配件数字化平台——06号遗留的"重汽千万元级海外配件平台"线索**未能证实，暂不采信**。

## 二、软件侧竞争格局（信息收集第4项）

### 2.1 车企海外DMS赛道：联友科技（重点剖析，✅官网全文）

2026-07-22发布《联友DMS助力车企数智营销出海》，恰在2026上半年出口509.6万辆(+65.3%)的历史拐点后——**在位大厂已明确把"车企出海"当作独立的战场来经营**。

| 维度 | 联友的情况 |
|---|---|
| 背景 | 深圳联友科技，东风系（东风南方集团下属），汽车行业数字化老牌供应商 |
| 架构 | 微服务；覆盖**线索跟进、整车销售、售后服务、备件管理**四大业务域；主机厂-经销商-服务站三级协同 |
| 备件模块能力 | 串联主机厂/服务站/供应商/物流商；需求提报→订单审核→资源调配→发运跟踪；智能配货；**替换件自动匹配**；缺件采购计划自动生成；全链路跟踪；盘点/调整/移库 |
| 海外套件 | 海外SaaS支付中心、海外智能网联平台、G-LES国际供应链、智能诊断（电池预警/远程维修指导） |
| AI能力 | 智能外呼、智能客服（大模型+知识库）、智能诊断知识平台 |
| 客户展示 | 东风日产等（成就客户页多为脱敏表述） |

**关键判断**：联友的备件模块管的是"OEM体系内的备件业务流程"，其配件主数据仍依赖各OEM自己的产品数据——**它不解决、也不打算解决"跨品牌中国商用车件适配目录"问题**。它做主机厂生意（大预算、长周期、总包制），不做汽配商生意。

### 2.3 汽配商软件（A/B线的直接竞品）

**国内：**
- **汽配云（qpyun.cn）**：汽配ERP+AI智能报价（30秒响应）+扫码出入库+手机端；官网未见公开报价（✅产品功能/❓价格需询价）；
- **一配云（1pei.me）**：汽配智能化云管理+报价系统，生态互联对象包括**汽配云、汽配旺旺、拾车道、用心**——说明国内汽配软件生态已有一批玩家互相打通（◻️）；
- 智百威等老牌汽配软件商；管家婆（通用进销存国民级）；
- 价格参照：低代码ERP基础版约8,000元/年（◻️简道云口径）；管家婆类通用产品数百~数千元/年。

**俄语区：**
- **PartsSoft**（✅官网定价页）：SaaS三档——Старт 10,250₽/月、Магазин 12,750₽/月、Сеть 14,500₽/月（约合110~160美元/月），一次性实施36,000₽（约400美元），高阶自48,000₽起；功能覆盖网店+批发+仓库+CRM+财务；
- **ABCP**：自称"汽配网店第一平台"，全套餐含仓库账务与CRM，主打"交钥匙"方案与1C集成（✅官网主张/❓价格需询价）；
- 1C生态（Управление торговлей/Альфа-Авто）仍是库存管理的底座。

### 2.4 竞争地图：三个空位与委托方定位

```
              配件目录数据（跨品牌中国件适配）
                        │
        【空位①】——无玩家解决，委托方最大机会
                        │
  汽配商客群 ──────────┼────────── 主机厂客群
  【空位②】            │           联友/用友/东软/远程慧联
  国内:汽配云们(无出海) │           （正面战场，不可入）
  俄语区:ABCP/PartsSoft │
  (无中国件目录)        │
                        │
              轻量/性价比段
        【空位③】小众车企与中小汽配商
        大厂不愿做小单，小厂做不了大集成
```

**委托方定位建议**：不做"又一个海外DMS"与联友正面竞争；做**"配件目录+B2B交易层"的单点专家**——向上可与联友/用友类DMS集成（福田DCMS招标本身就把"嵌套EPC"作为集成项，说明车企习惯分层采购），向下服务汽配商与OEM海外公司的配件业务。对车企客户的投标话术："我们不替代您的DMS，我们做DMS做不了的中国件适配目录与B2B商城。"

### 3.2 频次推断与局限

- 公开可查：约**8起/2年 ≈ 4起/年**；
- 重要修正：车企大量采购不走公开挂网，而走**邀标/比选**（福田DCMS公开版就是"比选采购"，且只在官网发布——"其他媒体转载无效"）；真实市场估计为公开口径的**2~3倍，即8~12起/年**；
- 分布推测：3~4家头部（重汽/解放/东风/陕汽/福田）+ 二线（江铃/三一/徐工/远程）+ 小众（北奔/北汽重卡/汉马/大运）合计15~20家有海外业务的车企，每家1~3年滚动建设一轮，与估算吻合；
- **局限（诚实声明）**：各车企招标分散在自有电子平台（福田fips、东风etp、重汽ygcgfw+官网、三一igsp、北汽重卡官网等），无统一索引；本次统计基于搜索引擎可达样本，**不能视为全量**。完整census需注册各平台并按月巡检。

### 3.3 对"3~5套"标准的直接回答

- C线（车企项目）：新进入者（无3案例+1海外案例资质）初期**现实可得1~3起/年**，且需通过代理商通道或先补案例；
- 结论：**单靠C线凑不齐"3~5套"的确定性**，必须 C+B 组合：C线2~3个大项目（200万+/个）+ B线3~5个汽配商/海外仓客户（10~50万/个），既满足金额又满足案例门槛（福田资格要求中"3个汽车行业案例"正可用B线项目填充）。

## 五、对委托方的启示（更新）

1. **放弃"整体替代"幻想，确认"单点切入"路线**：联友2026年7月的动作意味着任何标注"海外DMS"的正面提案都将撞上东风系大厂——委托方产品应定位为**配件目录+B2B商城+多语言交易层的专业单点**，以集成伙伴身份进入车企体系（福田招标中"EPC嵌套"证明车企接受分层采购）。
2. **B线客群价值上调**：联友/用友不服务汽配商——B线（出海汽配商）是**无直接软件竞争**的客群，且是福田资格门槛（3个案例）的最佳填充来源。
3. **空位①（目录数据）必须尽早验证**：它同时是B线的卖点和与联友类DMS的集成点。行动：调研中国商用车副厂件厂商（如各大滤清器/刹车片厂）是否已有标准化电子目录可合作授权。
4. **监测机制落地**：按月巡检6个平台——福田fips.foton.com.cn、东风etp.dfmc.com.cn、重汽ygcgfw.com+sinotrukinternational公告栏、三一igsp.sany.com.cn、北汽重卡beijingtrucks.com、北奔/乙方宝等聚合站。
5. **保持警惕的两个信号**：联友若发布"商用车海外版"专项产品；汽配云若推出多语言/跨境版本——任一出现即压缩空位②，应触发产品节奏提前。
