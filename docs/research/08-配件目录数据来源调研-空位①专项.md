# 配件目录数据来源调研（空位①专项）：跨品牌中国商用车件适配目录的可行来源

> 时间：2026-10-24 ｜ 性质：承接 [07号报告](07-软件侧竞争格局与招标频次统计.md) 空位①——"多品牌中国商用车件适配目录，无玩家解决"。本报告回答：**这个目录的数据从哪来、合法吗、多少钱、先做哪个品类**
> 证据分级：✅ 原文核实 ｜ ◻️ 检索摘要 ｜ ❓ 待询价/待验证

## 一、结论先行

1. **空位①再次确认**：全球多品牌商用车件目录标杆 Diesel Technic（5万SKU）只覆盖欧卡七品牌（Iveco/MAN/奔驰/DAF/雷诺/斯堪尼亚/沃尔沃，✅官网），**不含中国卡车**；TecDoc虽有700+中国企业入驻（✅泰案联苏州），但以乘用车件为主；国内数据商中精友明确宣称覆盖商用车（13,000+车型/65万+配件，✅官网），但它是通用数据服务商，没有"跨品牌中国商用车件B2B适配查询"的产品形态。**"目录"这个位置确实空着。**
2. **数据没有单一来源，只有"三条腿"组合**：OEM EPC授权（慢、贵、逐品牌）+ 副厂件厂商共建（主力、法律最干净）+ 贸易商数据合作（冷启动最快）。数据服务商（精友类）可做底座采购。
3. **目录是慢资产，恰好是护城河**：逐品类、逐品牌啃数据的活儿，大厂（联友类）看不上、小厂做不动——这与委托方"轻启动、3~5套"的节奏匹配：**目录从第一个客户的项目里长出来，而不是先建库再卖系统**。
4. **新发现的双重机会**：新瑞立（商用车配件供应链龙头：265家直营门店、32.6万SKU储备、港股IPO中 ✅）——既是B线潜在系统客户（多品牌配件分销商），又是潜在目录数据合作方。建议列入触达名单。

## 二、五种数据来源逐一评估

### 来源1：OEM EPC授权（原厂电子配件目录）

| 项 | 内容 |
|---|---|
| 现状 | 重汽在线EPC已存在：epc.sinotruk.com:7001 "SINOTRUK Global Service System"（备件查询/配件图册/整车BOM，需账号，面向授权经销商与服务站，✅）；福田EPC（epc.foton.com.cn）——福田DCMS招标正是"EPC嵌套"模式（✅ 06号文档）；解放/陕汽等预计同类 |
| 法律状态 | 专有数据，第三方使用需书面授权（◻️ vixiu对重汽EPC的描述）；授权费无公开价目 |
| 覆盖 | 单品牌、深（BOM级） |
| 判断 | **中长期动作，不是冷启动动作**。合理路径：随C线项目逐品牌谈——车企采购您的系统时，其EPC数据自然嵌入（福田模式），目录资产随项目累积。⚠️ 注意：直接抓取/复刻EPC图册有版权风险（vixiu等灰色资料站的存在说明需求真实，但不可作为商业产品基础） |

### 来源2：副厂件厂商电子目录（本报告主题，★主力来源）

| 项 | 内容 |
|---|---|
| 现状 | 国内副厂件厂商（滤清/刹车/离合/车身件等）普遍只有 Excel/PDF 价目表 + OE参考号对照，**无结构化适配数据**；PCFitment这类公司 existence 本身就是证据——它的生意就是替中国配件厂把适配数据做成ACES/PIES结构（✅官网：定制电子目录、ACES/PIES、DMS同步、对接Shopify/亚马逊/eBay） |
| 国际标杆 | Diesel Technic模式：厂商自有跨品牌目录（适配关系由厂商研发并维护），partnerportal发布36,547个卡车件（◻️），每季度更新——证明"副厂件厂商+结构化跨品牌目录"是被验证40年的商业模式 |
| 行业动向 | **温州汽配产业带抱团共建"车型适配数据库"**——产业协会层面已把"车型适配"列为全行业第一大痛点并组织共建（◻️ 2026报道）：证明厂商有意愿、缺的只是标准与工具 |
| 法律状态 | **最干净**：适配关系由厂商自己声明并维护，委托方做标准与平台，双方共有/授权使用 |
| 成本信号 | PCFitment定价（✅定价页）：$15/月(150SKU)→$150/月(3000SKU)，每+500 SKU加$25——说明**单厂商数据结构化服务的市场价是百美元级/月**；委托方反向操作：补贴头部厂商（每家数千~数万元/年量级）换结构化数据授权，即可启动 |
| 建议品类顺序 | 商用车易损件先行（滤清器→刹车片/蹄片→离合器→悬挂/钢板→驾驶室覆盖件）——通用性强、SKU集中、副厂件渗透率高 |

### 来源3：数据服务商采购（底座捷径）

| 厂商 | 商用车覆盖 | 备注 |
|---|---|---|
| **精友世纪**（jingyou.net） | ✅ 官网明确：车型库覆盖99%国内车型、13,000+车型、65万+配件，**覆盖商用车**；EPC数据服务（整车BOM结构、爆炸图、OE数据、适配关系） | 国内最接近"商用车适配数据底座"的采购对象；❓深度与授权范围待询价 |
| 昂美数据（51macc） | 亿万级SKU、VIN解析95%、EPC BOM爆炸图（✅官网）；以乘用车全车件为主 | 商用车深度❓ |
| TecDoc/泰案联 | 苏州公司2016年成立；**700+中国企业已注册TecDoc数据供应商**（✅）；有商用车数据板块，但中国企业发布以乘用车件为主；泰案联东南亚在做"OE数据调研"（◻️）——说明连泰案联自己都在补新兴市场的OE数据 | 合规接入全球售后体系的中长期通道；商用车中国品牌覆盖❓ |
| 开思 | VIN数据库+全车件数据；2025-12开思国际发布"T+D"出海模式（300+云工厂、9000+云仓）（◻️）——**开思已亲自出海**，定位乘用车全车件 | 竞争预警：若开思把出海延伸到商用车件，空位窗口收窄 |

### 来源4：多品牌件品牌商（Diesel Technic / Sampa类）

- DT 5万SKU**仅欧卡**（✅）；土耳其Sampa等同类。**中国品牌商用车件领域不存在"中国版DT"**——这既是空位确认，也是一个远期定位选项：委托方的目录+标准工具，未来可以成为"中国版DT"的载体（把国内副厂件厂商组织起来，用统一目录卖向海外）。远期战略选项，不改变短期打法。

### 来源5：贸易商积累数据（冷启动最快）

- 济南/山东贸易商（HowoParts、Sinosoon等）靠"哪个件适配HOWO/陕汽"的know-how吃饭，OE号↔副厂号对照数据以Excel/私有库形态存在（✅ 03号报告已述其模式）；
- 法律状态：灰色——事实性对照数据（OE号对应关系）受版权保护弱，但**图册/BOM图/图片直接复制有侵权风险**；合作时应约定"数据清洗+重新结构化"，不搬运原始图册；
- 成本：合作或买断成本低（相对其营业额）；**与B线触达天然重合**——B线访谈的第一批对象（济南系海外分支）就是数据合作的谈判对象。

## 三、推荐组合策略：冷启动 → 护城河

| 阶段 | 动作 | 产出 | 成本量级 |
|---|---|---|---|
| **阶段0（0–3个月，随B线访谈）** | 与1~2家济南系头部贸易商谈数据合作（OE↔副厂号对照，聚焦HOWO/陕汽/解放三品牌）；同步向精友询价商用车数据底座 | HOWO/陕汽易损件适配的MVP目录（数百~数千SKU级） | 数万~十万元级 |
| **阶段1（3–12个月，随首个客户项目）** | 选滤清器品类，参照温州共建模式与2~3家头部厂商签"标准+工具换数据授权"协议；目录结构兼容TecDoc/ACES导入格式 | 结构化的单品类跨品牌目录；成为产品演示的核心资产 | 每厂商数千~数万元/年补贴 |
| **阶段2（12个月+，随C线项目）** | 逐品牌谈OEM EPC授权（从已合作车企开始，复制福田"EPC嵌套"模式）；目录扩品类、扩品牌 | OE+副厂双轨目录——竞品（联友类/ABCP类）短期无法复制 | 项目内消化 |
| **远期选项** | 目录独立成"中国版Diesel Technic"载体（组织国内副厂件厂以统一目录出海） | 目录本身成为可独立变现的资产 | 战略级 |

**关键原则**：目录从客户项目里长出来（先有HOWO的单，再养HOWO的目录），不搞"先建大而全数据库再卖系统"——那会重蹈大厂重资产覆辙，也违背"3~5套即可做"的资金纪律。

## 四、对产品架构的具体要求（供研发参考）

1. 目录数据模型需支持：**OE号 ↔ 副厂号 ↔ 适配车型（品牌/车系/年款）** 三向映射 + 图册位图化（规避EPC图片版权）；
2. 导入/导出兼容 TecDoc 与 ACES/PIES 格式——与全球售后生态和国内数据商（精友/PCFitment产出）双向兼容；
3. 多语言字段从第一天内建（福田DCMS要求中英泰俄西德的教训）；
4. 数据质量工作流：厂商自维护 + 平台审核 + 经销商纠错反馈闭环（DT每季度更新的节奏可作基准）。
