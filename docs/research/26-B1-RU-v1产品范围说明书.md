## 一、产品一句话与商业模型

**给"把中国汽配卖到俄罗斯"的运营者（对俄贸易商/在俄华商/厂商海外部）的一套私有化部署的俄语商城单体系统**：买家（修理厂/汽配店/车主）按车找件、以 30 天限时价明码直购；卖家中文后台管商品、订单、库存与赋码；车型/适配目录数据由开发商总仓以版本化数据包持续供给，客户自补数据回流总仓。

| 商业要素 | 内容 | 出处 |
|---|---|---|
| 产品形态 | **SKU-B：私有化部署**（单体，一个部署单元） + **数据订阅年费**（数据包更新） | 24号 |
| 首建定价基准 | 贸易商 10–30 万 / 华商 10–50 万（含赋码），**含初始数据包**（按品类包计价） | 21号/24号 |
| 持续收入 | 数据订阅年费（新车型的俄市命名映射、新增适配、交叉号、纠错）——年费的实质内容 | 24号§五 |
| 首客路径 | 第一客=济南系对俄贸易商；第二客=在俄华商（赋码话术开门）；M 版运营者不做 | 21号§六 |

## 三、系统构成与部署

```
【交付物：一个单体应用 → 客户俄云账号/自有服务器】
├ 前端① 商城客户端（俄语，买家）
├ 前端② 商城管理端（中文，运营方员工）
└ 单体后端
   ├ 交易域 commerce：商品/订单/收单支付/库存/客户/赋码/限时价/对账
   └ 目录域 catalog：CDD3 目录域受控派生（只读查询+数据包导入+补录暂存+码实例）
   一个数据库 · 一套 docker-compose
【不交付，开发商内部】
CDD3 数据总仓（data_platform 原身）：数据加工/俄语化/包构建/回流审核
        │ 版本化数据包（订阅期下发，异步可断连） ▲ 补录回流（变更集）
```

- **断网自足**（✅裁定）：买家全部查询走实例内镜像；在线依赖仅限两类交易功能——支付网关与 ЧЗ API；
- **242-FZ**：个人数据存储于俄境内；部署目标建议写明"客户俄云账号"（❓ 首单合同定）。

### 4.5 N2 赋码（按 25号规格）

**P0（导入式先行）**：赋码品类字典（ТН ВЭД 匹配）、码实例状态机（订/贴/入转/在库/出转/退回）、收货验码、按码出库、退货回转、标签打印工作台（F-16）、码报表。
**P1（直连）**：ЧЗ 开放 API 四点（订码缓冲/入转/出转/退货重入转，测试环境先行）+ ЭДО УПД。
时间锚（✅25号）：2026-12-01 进口商报关前贴码；存量缓冲至 2027-06-01——v1 交付期落在合规窗口内。

### 4.6 支付与资金——P0

- 在线收单：SBP/银行卡（网关❓首单定：ЮKassa 类）+ **54-ФЗ 电子小票**（俄线上零售法定）；
- 对公转账：转账指示 + 到账人工确认核销；
- 资金边界：钱进运营方俄方账户；**结汇不在系统内**，系统出对账单（✅裁定3）。

## 五、明确不做清单（v1）

1. M 版/多供应商聚合、平台撮合（✅裁定）；
2. RFQ/询价车与报价聚合（与限时价定位相悖）；
3. 三电件（电池/电驱/电控）目录与销售；
4. 自营库存与 WMS（对接客户自有仓）；
5. 平台代收付与跨境结汇通道；
6. 面向俄本土商的整体系统（只做中国件商城，07号纪律）；
7. 中俄之外的语言（英语/阿语随 B1 中东线另议）；
8. C 端消费附件类目（脚垫/坐垫等非适配型商品）；
9. SaaS 多租户形态（已裁 SKU-B）；
10. 人工代运营/代贴标服务（转介合作方，单维护者时间保护）。

## 六、非功能需求

| 项 | 要求 |
|---|---|
| 断网自足 | 停外网出向后，买家浏览/找件/下单/对公流程完整可用 |
| 性能 🟡 | 找件查询（实例内同库）P95 < 500ms |
| 部署 | docker-compose 单部署单元；数据库迁移只向前兼容；数据包 schema 版本与代码版本双轨 |
| 授权 | 订阅状态实例侧校验+离线宽限；**不远程锁死**（机制细节 ❓ 开发期定） |
| 安全 | 管理端 RBAC 分角色；支付数据不落盘（网关托管）；个人数据俄境内存储（242-FZ） |
| i18n | 全部界面文案走语言包（ru/zh），禁止硬编码 |
| 多币种 | 卢布展示 + 人民币/美元底价、汇率规则（限时价的计价基础） |

## 七、冷启动依赖与关键路径（与开发并行）

1. **供给锚 ≥2 家**（20号 Gate 0 延续）——碰撞件为主，签独家上架+固定价+直发协议；
2. **初始数据包 500–2,000 行**（G-02）——首客部署的硬前置，数据工作即刻启动；
3. 俄市车型骨架+命名映射表（G-03）；
4. 支付网关选型与合同（❓）；
5. 首客签约（济南系对俄贸易商）——**Gate 1 = 首个标准品付费客户**。

## 九、验收标准（v1 DoD）

1. 首客俄云账号部署成功；停外网出向后买家全流程可用（断网自足验证）；
2. 按车找件 → 限时价下单 → 在线支付/对公 → 履约 → 对账，真实试单 ≥1 笔；
3. 数据包导入与版本更新演练通过（幂等、schema 校验）；
4. 受控品类码实例全生命周期演练（导入式：清单导入→收货验码→按码出库→退货回转）；
5. 限时价到期自动下价验证；
6. 补录暂存与回流导出演练。
