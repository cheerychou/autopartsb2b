# B1 三场景调研与对比论证：出海汽配 B2B 在线销售系统

> 时间：2026-10-24 ｜ 性质：候选一（B1 出海汽配商数字化套装）落地前场景论证
> 委托方裁定（本轮前提）：**不区分乘用车/商用车**——品类只是数据授权问题，不影响产品方向；产品形态 = **以汽配商、汽配生产商为核心用户、以海外市场为应用场景的汽配 B2B 在线销售系统**
> 证据分级：✅ 原文核实 ｜ ◻️ 检索摘要（待复核）｜ ❓ 待询价/验证

## 一、结论先行

| 排序 | 场景 | 一句话判定 |
|---|---|---|
| **1** | **济南系配件商出海业务** | 客群规模最大、中文可及、付费信号明确（已为建站付1~10万）、零合规障碍——**首发场景** |
| **2** | **中东华人汽配商** | 付费能力最强、一次出差可批量触达（迪拜德拉华商500~800家），双语+多币种是清晰卖点——**第二站** |
| **3** | **俄罗斯汽配商** | 痛点最深但障碍也最深（1C生态壁垒+支付制裁+赋码合规）——**择机轻切入，合规前置** |
| 补充 | **汽配生产商**（厂商版） | 与经销商版同内核异形态（目录方vs销售方），随济南系/产业带推进，温州共建运动是入口 |

**统一产品内核（三场景共用）**：前台 = 多语言 B2B 商城（按车找件目录 + OE/货号检索 + 询盘车RFQ + 订单跟踪）；后台 = 进销存 + 客户/账期（CDD3 复用）；数据层 = 适配目录（CDD3 fitment，08号三条腿供给）。

## 二、场景一：济南系配件商的出海配件业务

### 2.1 客群画像与规模
- 山东汽车零部件出口约78亿美元(+12.3%)，其中商用车配件约31亿美元，俄/中东/非洲为主要目的地；**济南周边商用车配件贸易企业约1,200家**（◻️ 地方口径，待复核）；
- 经营品类：HOWO/陕汽/解放**全车件+易损件批发**，客户遍布俄语区/中东/非洲/东南亚；
- 经营模式（✅ 36氪调研 + ◻️ 地方报道）：**阿里国际站询盘 → 微信/WhatsApp报价 → 混柜拼单 → 线下成交**——"线上获客、线下交易"。

### 2.2 现有工具与数字化水平
- 库存/报价：Excel + 管家婆类单机；线上：阿里国际站店铺 + 通用外贸建站（模板站1~3万、定制10万+，◻️建站行情）；
- **线上化率低的根因已被点破**（✅ 36氪）：SKU与车型适配数据复杂，线上展示门槛高——通用建站方案"适配数据结构化能力弱"（◻️ 亿邦动力），这正是 CDD3 fitment 引擎的强项。

### 2.3 痛点 → 系统需求映射
| 痛点 | 系统功能 | CDD3 对应 |
|---|---|---|
| 询盘响应慢、多语言报价靠翻译软件 | 多语言报价单生成、询盘车（RFQ）转订单 | store-web 多语言+i18n骨架 |
| 报错价、发错件（适配错） | 按车找件目录 + OE/货号检索 | data_platform fitment ✅ |
| 无法向海外客户展示"按车找件" | B2B 商城前台（客户自助查询下单） | 新建商城前台（B1 P0） |
| 混柜出运状态靠微信问 | 出运/订单跟踪（轻量） | 订单状态扩展 |
| 账期与对账（老客户赊销） | 客户信用+对账单 | PRD-DS-FIN-007 底座 |

### 2.4 付费意愿与客单
- **关键付费信号：他们已经在为"独立站"付1~10万元**（建站行情 ◻️）——本产品 = 独立站 + 进销存 + 适配目录三合一，以"你已经付过建站钱，我们把它变成能接单的系统"话术切入；
- 建议客单：首建10~30万/套 + 年服务费；共建试点5~7折（10号协议要点）。

### 2.5 竞争与替代
- 通用外贸建站商（X系等）：无适配检索、无进销存——不在同一层；
- 阿里国际站：获客层而非系统层（✅ 02号 36氪结论）；
- 汽配云们：无出海形态（✅ 07号）。
- **判定：无同层竞争。**

### 2.6 可及性 ★ 最高
- 中文沟通、可实地拜访（济南/潍坊/临沂产业带）；委托方若在山东汽配圈有人脉则周期进一步缩短；
- 数据合作与系统销售天然合一：济南系手里的"货号↔车型"对照（08号来源5）就是共建的交换物。

## 三、场景二：中东华人汽配商

### 3.1 客群画像与规模
- **迪拜德拉（Deira）/也门门汽配商圈华商约500~800家**（◻️），主营中国产配件批发与转口；迪拜汽配年贸易额约370亿迪拉姆（~100亿美元），**转口占60~70%**（流向非洲/中亚/俄罗斯），华商约占转口份额30%（◻️）；
- 沙特（利雅得/吉达）华商规模小于迪拜、多依托迪拜转口（◻️）；沙特售后市场67亿→95亿美元（✅ 02号）；
- 哈萨克阿拉木图（巴尔恰克市场）华商300~500家（◻️）——与俄罗斯场景重叠的中间带；
- 业务结构：批发 + 转口 + 本地分销并存，多仓（迪拜转口仓 + 目的国仓），客户分级（零售/二级批发/车队）。

### 3.2 现有工具
- 通用ERP（迪拜市场已有通用ERP厂商渗透，✅ 07号 Cubix案例）或 Excel；部分接入当地B2B平台；**无适配目录、无汽配专用系统**；
- 中东渠道"高度碎片化、以批发商/展贸为主，无统治级线上B2B平台"（✅ 02号）。

### 3.3 痛点 → 系统需求
| 痛点 | 系统功能 |
|---|---|
| 阿语/英语双语操作（本地雇员用系统） | 多语言（阿拉伯语RTL布局是专项）|
| 转口贸易多币种/多客户分级定价 | 多币种计价、客户分级价格体系 |
| 迪拜仓+目的国仓库存联动 | 多仓进销存 ✅ |
| 本地分销账期文化 | 账期/信用管理 ✅（FIN-007底座） |
| 中国件适配目录 | fitment ✅ |
| 发票合规（阿联酋VAT/沙特Fatura电子发票❓） | 按国别发票模板（❓待专项核实） |

### 3.4 付费与竞争
- 华商付费能力高于济南系（转口毛利+境外经营成本），已为通用ERP付费——升级替换话术成立；客单10~50万可接受（🟡）；
- 竞争：通用ERP（无汽配目录）、当地B2B平台（无中国件目录）——**同层仍空**。

### 3.5 可及性与风险
- 可及性中：需赴迪拜（一次出差可批量触达德拉商圈数十家）或经华商会/展会（Automechanika Dubai）；
- 支付/合规无制裁障碍；主要成本是差旅与阿语支持；
- 风险：华商群体价格敏感、习惯"找熟人定制"，需靠标杆案例撬动。

## 四、场景三：俄罗斯汽配商

### 4.1 客群画像（两类，分开对待）
- **a) 俄本土多品牌汽配商**：信息化成熟——1C 生态底座 + ABCP"第一平台"/PartsSoft（✅ 07号），线上心智强（线上购买比例约55%，✅ 02号）；
- **b) 在俄华人汽配商**：依托莫斯科格林伍德（约500家中国企业入驻，含汽配，◻️）、柳布利诺市场设仓，服务当地维修厂/车队/中国卡车站点；哈萨克斯坦同类300~500家（◻️）；多以 Ozon/Wildberries 零售试水（汽配GMV+42%、中国卖家激增，◻️），**B2B线上化程度低**（◻️）。

### 4.2 痛点 → 需求
| 客群 | 痛点 | 系统形态 |
|---|---|---|
| 华人商 | 中国件适配目录缺失（1C/ABCP均无）、俄语雇员操作、**Честный знак 赋码（2026-12硬门槛）**、卢布收付 | 中文后台+俄语商城+赋码对接+1C数据互通 |
| 俄本土商 | 想卖中国件但没有目录数据 | **只切"中国件目录+1C对接"单点**，不做整体替代（07号结论） |

### 4.3 付费与竞争
- 本土SaaS锚：PartsSoft 10,250~14,500₽/月（✅ 07号定价页）≈千 元人民币级/月——订阅价带低；华人商定制10~50万（🟡）；
- 竞争强度三场景中最高：1C+ABCP生态成熟，正面无空间；**空位=中国件适配目录+赋码合规+中文服务**。

### 4.4 风险（三场景中最高，必须前置）
- 支付/结汇制裁敞口（04号Q5，未解决前不碰）；
- Честный знак 赋码合规（2026-12生效，是门槛也是卖点——谁先做对接谁拿到合规溢价）；
- 242-FZ 数据本地化（俄境内存个人数据）——部署架构约束；
- 地缘政策波动（2025禁售/报废税先例，✅ 03号）。

### 4.5 判定：择机轻切入
- 顺序：先解决结汇通道与赋码合规调研 → 以"目录+1C对接"单点服务华人商 → 不做俄本土商整体系统；
- 若2026年对俄出口恢复性增长持续（◻️ 05号待核实项），可提前。

## 五、补充论证：汽配生产商（厂商版，第二租户形态）

- **需求真实性**：生产商出海需要"品牌B2B独立站"——核心功能 = 产品目录（按车型/品牌/OE检索）+ **询盘车RFQ** + 多语言 + SEO（◻️ 亿邦动力）；且普遍**没有结构化适配数据**——PCFitment 的存在（$15~150/月替厂商做ACES/PIES，✅ 08号定价页）证明厂商愿意为适配数据服务付费；
- **与经销商版同内核异形态**：厂商租户 = 目录方（发布适配数据+品牌商城+经销商门户RFQ管理）；经销商租户 = 销售方（查目录+进销存+自营商城）——同一 fitment 数据层，两种前台；
- **获客入口**：产业带（温州"共建适配数据库"运动 ✅ 08号——厂商意愿已被组织化验证）、Automechanika Shanghai 等展会、汽配云未覆盖的出海厂商；
- **客单**：建站1~10万（已有付费习惯）+ 目录数据服务年费；单客金额低于经销商版，但**数量多、且是目录数据的供给方**（08号来源2）；
- **判定**：随济南系一并推进（山东/温州产业带），不单独立项。

## 六、三场景对比总表

| 维度 | 济南系出海 | 中东华商 | 俄罗斯汽配商 |
|---|---|---|---|
| 客群规模 | ~1,200家贸易企业（◻️） | 迪拜500~800家华商+沙特/哈（◻️） | 格林伍德500中企+柳布利诺+哈300~500（◻️） |
| 数字化水平 | 低（Excel+阿里询盘） | 低~中（通用ERP） | 本土商高 / 华人商低 |
| 核心痛点 | 询盘转化、适配错报错价、无线上目录 | 双语目录、多币种转口、账期 | 中国件目录、赋码、结汇 |
| 系统形态 | B2B商城+进销存+目录 | 双语批发+多币种多仓 | 中文后台+俄语商城+1C对接+赋码 |
| 付费信号 | ★已为建站付1~10万 | ★已为通用ERP付费 | PartsSoft订阅锚+定制10~50万 |
| 竞争强度 | 低（建站商无适配） | 低（通用ERP无目录） | 高（1C生态）但空位明确 |
| 可及性 | ★高（中文/可实地） | 中（赴迪拜/商会） | 中低（支付/合规/语言） |
| 政策风险 | 低 | 低（发票合规待核❓） | **高（制裁/赋码/数据本地化）** |
| 与C线协同 | 目录资产来源 | 案例+第二市场 | 存量案例富矿（谨慎） |
| **综合** | **★★★★★ 首发** | **★★★★ 第二站** | **★★★ 择机** |

## 七、落地建议

1. **首发济南系**：目标3家共建候选（产业带实地+10号清单），产品范围=11号P0五项，语种随首单客户（对俄客户多→俄语优先，但结汇方案须先落）；
2. **第二站迪拜**：济南系跑通后（约3~6个月），一次迪拜出差批量触达德拉商圈，标杆案例随行；
3. **俄罗斯轻切入**：结汇通道落地前只做"目录+对接"咨询与预研；Честный знак 对接作为 R&D 储备（2026-12前的合规溢价窗口）；
4. **厂商版随行**：济南系/产业带推进时同步签1~2家滤清器/刹车片厂商做"目录共建+品牌页"——既是客户又是数据供方（08号来源2闭环）；
5. **产品内核冻结**：前台多语言B2B商城 + 后台进销存/账期（CDD3）+ fitment 数据层——三场景共用，差异只在语言包/币种/合规模块，避免做三套产品。
