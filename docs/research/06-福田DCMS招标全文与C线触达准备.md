## 一、福田汽车"海外DCMS平台建设项目"招标公告（全文要点整理）

> 来源：北汽福田电子招标平台（fips.foton.com.cn），✅ 原文全文抓取成功
> 版本说明：本项目有两份公告——2024-04-25（招标公告，field.10jqka收录）与 2024-06-26（比选采购，本文档依据）。三个月内两次公告，提示需求紧迫或首轮流标。

### 1.1 项目概况

| 项 | 内容 |
|---|---|
| 招标人 | 北京福田国际贸易有限公司（实施单位：海外事业部） |
| 项目 | 海外境外法人公司 DCMS 统一平台（DMS+CRM 功能整合） |
| 建设内容 | 线上管理**整车、配件销售订单和服务索赔单**；与福田国内 DMS、国外第三方仓储系统（WMS）及福田其它自建系统实时数据集成 |
| 分期 | **一期：泰国合资销售公司的配件销售业务+服务索赔业务**；整车销售与线索管理规划二期（投标产品须具备相应基础功能） |
| 目标 | "取代目前纯手工线下作业的方式"（公告原文） |

### 1.2 功能需求清单（36项，即产品需求基线）

| 模块 | 功能项 | 期次 |
|---|---|---|
| 配件订单管理 | 订单提报、订单审核、合同管理、回款管理、订单状态跟踪、交付管理、发票管理 | 一期 |
| 配件库存管理 | 出库、入库、**查询属地第三方配件仓储系统库存** | 一期 |
| 配件产品主数据 | 配件产品信息、价格信息、**嵌套福田配件电子图册系统（EPC）** | 一期 |
| 配件财务管理 | 配件开票管理 | 一期 |
| 服务索赔管理 | 终端客户服务保养维修信息记录查询、索赔单提报、审核、结算 | 一期 |
| 销售线索管理 | 线索创建、分配 | 二期（基础功能本次必备） |
| 整车订单管理 | 订单提报至发票管理（7项，支持一车一BOM/G+X/全配置BOM） | 二期 |
| 整车库存/渠道/主数据/财务 | 出入库、实销、渠道信息与权限、产品价格、开票 | 二期 |

关键业务逻辑（公告"需求范围分析"）：
- 配件订单流：**法人公司下属二级经销商订单提报 → 法人公司审核 → 合同/回款/交付/实销**全链路；
- EPC嵌套：经销商通过DCMS查询配件电子目录和图册（系统与福田EPC集成）；
- 库存：法人公司配件库存经属地第三方物流管理，DCMS须对接属地第三方物流**WMS实时查询库存**，并设安全库存功能；
- 索赔流：二网索赔单提报→**与国贸OTD系统对接**，自动转化为向国贸提报的索赔单，"避免重复录入和跨系统操作"；
- 报表：进销存等统计报表并反馈给经销商。

### 1.3 非功能与部署要求

- **多语言**：中文、英文、泰文、俄文、西语、德语（"包含但不限于"）；
- **部署**：数据中心在**中国境外公有云部署，境外数据脱敏中转**；
- **集成面**：国内DMS + 属地第三方WMS + 福田EPC + 国贸OTD + 属地财务记账系统——典型的"海外中台"定位。

### 1.4 投标人资格（=委托方的资质对照清单）

| 要求 | 内容 |
|---|---|
| 主体 | 法人；成立1年以上；近3年无违法违纪；非失信被执行人；关联回避 |
| **案例门槛①** | 近3年**3个**汽车行业销售/服务系统平台项目案例（须提供合同首尾页+盖章页原件扫描，附《技术协议》或SOW） |
| **案例门槛②** | 近3年**至少1个国外实施**的汽车行业销售/服务系统案例 |
| 产品 | 海外公有云部署环境；多语言（中英泰俄西德） |
| 模式 | **接受代理商投标**（需产品授权书）；不接受联合体；不可分包 |

### 1.6 对委托方产品的四个直接价值

1. **需求基线白拿**：36项功能+五大集成接口，可直接作为产品Backlog与报价结构模板——这就是"海外商用车配件销售系统"的行业级规格书；
2. **最小可行范围已划定**：一期只做"单国法人公司+配件订单+索赔+EPC嵌套+WMS对接"——验证了"单市场、配件先行、整车二期"的切分方式，与委托方构想一致；
3. **资格门槛明确**：3个国内案例+1个海外案例+海外云+多语言。委托方当前的差距是"汽车行业案例"与"海外实施案例"——可通过 B线（出海汽配商）案例补位，或以代理商模式（与已有资质的系统商联合、委托方出产品）进入；
4. **商业模式旁证**：福田选择"境外法人公司统一平台"而非各国自建——平台型产品在车企海外体系内有明确位置，且"纯手工线下作业"是车企自己承认的现状。

## 二、大运汽车重整尽调结果（✅ 已核实）

| 时间 | 事件 |
|---|---|
| 2024-11-25 | 大运汽车以重整清算组管理人身份发布声明：**"没有破产，仅重整新能源板块（大运新能源汽车、远航汽车），重卡等商用车板块不在重整范围内"**（第一财经、卡车之家 ✅） |
| 2026-09-17 | 山西运城中院裁定批准《**大运汽车股份有限公司等58家公司重整计划**草案》——重整范围已扩大至集团层面 |
| 2026-09-22起 | 进入重整执行阶段；公开报道口径**负债约55亿元**；"重整计划的落地，需要持续稳定的生产经营、投资人资源加持"（财闻、腾讯新闻、搜狐timeline ✅） |
| 投资人 | **产业投资人名单未见公开确认**（检索未见最终落地披露）——执行阶段关键变量 |

背景：大运汽车股份有限公司成立2007年，法定代表人远勤山，注册资本10.7亿，主营专用车/商用车/新能源车；重卡巅峰期年销约3万台。

**尽调结论**：⚠️ **暂缓触达，列入观察名单（季度复核）**。理由：①重整已从新能源板块扩大到集团58家公司，合同存续与付款能力不可靠；②IT采购在重整执行期大概率冻结；③反向机会：若重整计划执行、新投资人落地，IT系统重建往往是重整后第一批采购——届时重整后的大运反而是优质销售窗口。**触发条件：确认产业投资人落地或重整计划执行完毕。**
