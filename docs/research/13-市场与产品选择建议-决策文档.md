# 市场与产品选择建议（决策文档）

> 时间：2026-10-24 ｜ 性质：收官决策文档——综合 05~12 号全部证据，列出候选市场×产品组合供委托方拍板
> 决策标准（委托方既定）：解决方案商视角；研发成本（约10万/年）vs 销售收入；3~5套即可做；不做一手访谈（以售代研）

| # | 事实 | 证据 |

| 1 | 车企海外DMS正面战场已被大厂占领（联友2026-07入场），但**小众车企轻量段、汽配商客群、跨品牌中国件适配目录**三个空位仍在 | 07号 |
| 2 | 委托方当前资质无法直投车企大额标（案例3+1/CMMI/注册资本），但有供应商入库、小额询价、代理商三条即时通道 | 12号 |
| 3 | CDD3 数据平台+门店产品使研发边际成本趋近于零，且**适配目录（空位①）的载体已经存在** | 09号 |
| 4 | B线客群（出海汽配商）**无直接软件竞争**（汽配云们不出海、ABCP/PartsSoft无中国件目录），且海外项目可能恰好满足福田"1个国外实施案例"资格条款 | 07/12号 |

## 二、五个候选方案

### 候选一：出海汽配商数字化套装（B1）★ 主推荐

| 维度 | 内容 |
|---|---|
| 市场 | **中国背景出海汽配商**：济南系贸易商海外分支、中东华商（迪拜/沙特）、俄语区中国件经销商；标杆对象：新瑞立（265店/32.6万SKU） |
| 产品 | 多语言（俄/英/阿）配件进销存 + 客户自助下单商城 + **适配目录查询**（OE↔货号↔车型）+ 账期管理 + 移动端 |
| 首单路径 | 10号售前清单接触3~5家 → 1~2家共建试点（5~7折换需求输入+案例授权） |
| 经济性 | 10~50万/套；3~5套 = 50~250万；**首套共建即覆盖年研发** |
| 周期 | 首单1~3个月；本月即可开始 |
| 竞争 | 无直接竞争者（空位②）；差异化=适配目录+中文服务+出海场景 |
| 风险 | 客户付费能力参差（贸易商利润薄）；单套金额小需要走量 |
| 资产匹配 | ★★★★★（store-web/data_platform/warehouse/移动端全部复用，补多语言+商城前台） |
| 战略附加值 | 海外案例→福田资格条款；适配数据→目录资产（08号三条腿） |

### 候选二：小众车企海外配件系统·轻量版（C1a）

| 维度 | 内容 |
|---|---|
| 市场 | 北奔/北汽重卡/三一/徐工/江铃等有海外业务但IT弱的车企（+大运待重整落地） |
| 产品 | 福田DCMS对标的一期子集：海外法人公司配件订单+库存+多语言商城+索赔单流 |
| 首单路径 | 供应商入库（本月）→ 10~50万询价级小单（单模块：目录查询/WMS对接）→ 2~3年后案例达标投大标 |
| 经济性 | 首单10~50万；成熟期200万+/项目 |
| 周期 | 首单6~18个月（采购节奏决定，不可控） |
| 竞争 | 联友等大厂不做几百万级小单——轻量段空位；但招标关系型强 |
| 风险 | 资质门槛（正在积累）；销售周期长；单维护者精力 |
| 资产匹配 | ★★★★（多语言/B2B门户/索赔流为缺口，约50-60%复用） |
| 定位 | **第二阶段目的地，不是首发地** |

### 候选三：ISV产品经SI代理进车企生态（C1b）

| 维度 | 内容 |
|---|---|
| 市场 | 有汽车行业案例资质的SI/服务商（他们缺差异化产品） |
| 产品 | CDD3数据平台+配件B2B模块以**产品授权**形式供SI投标集成 |
| 经济性 | 授权费/许可分成（单项目数十万级），不承担实施 |
| 周期 | 取决于SI的项目管道 |
| 风险 | 客户关系归SI；需找到愿意合作的SI（人脉依赖） |
| 定位 | **机会型通道，遇合适的SI就做，不主动主攻** |

### 候选四：国内汽配商"解决方案包"（A1）

| 维度 | 内容 |
|---|---|
| 市场 | 国内中型汽配商（单机版/Excel用户中的项目制客户） |
| 产品 | 汽配商城 + 数字化门店（上下游数据打通+适配查询——fitment引擎是汽配云没有的） |
| 经济性 | 数十万/套项目制；SaaS订阅价带（千元/年）不满足3~5套标准，**不做** |
| 竞争 | ⚠️ 汽配云/智百威活跃——唯一的差异化是"打通"与适配查询 |
| 定位 | **备选/现金牛候选**：若B1拓客遇阻，退回国内；不与B1并行（精力） |

### 候选五：适配目录数据产品（B2，独立形态）

| 维度 | 内容 |
|---|---|
| 市场 | 配件出口厂商（需要结构化适配数据上架海外平台）、跨境电商卖家 |
| 产品 | PCFitment式的适配数据定制/目录订阅（对标其$15~150/月定价） |
| 经济性 | 低客单、高变动；**独立成生意太薄** |
| 定位 | **不独立做，作为候选一/二的内置差异点**；远期（目录资产成形后）可独立变现为"中国版Diesel Technic" |

## 三、推荐：**B1先行、C线跟进、目录贯穿**（三阶段路线）

| 阶段 | 时间 | 动作 | 里程碑 |
|---|---|---|---|
| 0 | 本月 | ①5个车企采购平台供应商入库（12号§6）②**委托方按自身需求理解定义产品（2026-10-24裁定：不做共建候选阶段，15号形态定义+11号清单作为自研参考基线）** | 产品定义完成 |
| 1 | 0~6个月 | 产品开发（AI原生，约10万/年成本口径）+ 标准品销售启动 | **首个标准品付费客户**（Gate 1重新定义） |
| 2 | 6~18个月 | B1复制3~5套（10~50万/套）；C线询价小单1~2个（通道B）；目录资产跨品牌成形 | 年收入50万+；案例3个 |
| 3 | 18个月+ | C线大标正式投标（案例达标）；目录远期独立（候选五） | 首个200万级项目 |

**为什么不推荐其他组合**：①A1+B1并行——精力分散且A1直面汽配云价格战；②C1a首发——资质与销售周期不允许，只能跟进不能首发；③纯B2数据产品——客单太薄养不活公司；④平台撮合——委托方已明确排除。

## 四、只有委托方能回答的三个决策输入

1. **销售资源在哪**：您（或合伙人）现有的人脉/渠道更接近"海外汽配商圈"还是"车企圈"？——决定B1首客从哪个圈起（答案不影响B1主推，只影响首客来源）。
2. **共建模式接受度**：首单5~7折+深度服务换案例与数据，是否接受？（候选一的前提）
3. **首发语种/地域**：跟首个客户走（俄语→哈萨克/莫斯科；英语/阿语→迪拜），不做预设。

## 五、一句话总结

> **给"中国出海汽配商"做"多语言配件商城+适配目录"系统（候选一），首客用共建模式从济南系贸易商或新瑞立中产生；同步注册车企供应商库、把每一个B线项目变成C线投标资格——研发端CDD3已备好，这是唯一一条"本月就能动手、且每一步都在为下一步铺路"的路线。**
