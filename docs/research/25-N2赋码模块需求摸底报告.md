# N2 赋码模块需求摸底报告（Честный знак 汽配赋码）

> 时间：2026-10-25 ｜ 性质：[22号](22-CDD3数据平台复用边界与集成方案.md)§五摸底清单的产出物——落实委托方裁定"系统直连，先摸清功能需求再动手"
> 方法：俄语源检索约 10 次，Kontur.ru 与 SelSup 两篇指南原文抓取 ✅
> 证据分级：✅ 原文核实 ｜ ◻️ 检索摘要（待复核）｜ ❓ 待询价/待核 ｜ 🟡 建议/推断

## 一、结论先行

1. **品类范围有限，首发品类不在清单内（重大利好）**：强制赋码的是**滤清器、火花塞、汽车玻璃、刹车盘/片、轮毂（+轮胎、机油已先行）**——**车身碰撞件（保险杠/翼子板/大灯等，20号推荐首发品类）不在清单**。赋码只影响易损件销售线，不影响首发主打线。
2. **时间线已完整且分层**：2026-09-01 全体参与者注册（已生效）→ **2026-12-01 起生产商与进口商赋码（进口须报关前贴码）**→ 存量未码货可售至 2027-06-01 → 2027-12-01 起 УПД 按码传输（ЭДО）→ 2029-05-01 前完成按件管控过渡（◻️ 两源口径略有差异，见§二.3）。
3. **"系统直连"范围已可规格化**：需求摸清到能写《N2 需求规格》的程度——数据模型增量、四个 API 对接点、一条跨地域工作流（§三）。不再是"生死细节"，是排期项。
4. **成本对经济性影响可忽略**：码费 0.6 卢布/码（含 VAT，◻️）——一件 1,000₽ 的刹车片赋码成本占 0.06%；真金白银的成本在设备、ЭДО 与人工流程，且多为客户侧一次性投入。
5. **对华商客户的核心工作流是跨地域的**：贴码发生在**报关前**（中国仓/保税仓），核销发生在**俄境销售**——系统必须支持"管理端从中国远程登录打印标签 + 俄境收货验码/销售核销"两个场景，无需新增应用（23号交付结构不变）。

## 二、七项摸底结论（对应 22号§五清单）

### 2.1 合规主体

| 项 | 结论 | 分级 |
|---|---|---|
| 注册义务 | 2026-09-01 起**全体流转参与者**（生产商/进口商/批发/零售/电商平台）须在 Честный знак 注册 | ✅ Kontur/SelSup |
| 贴码义务人 | 2026-12-01 起**生产商与进口商**订码、贴码、入转 | ✅ Kontur |
| 华商客户形态 | 以俄法人（ООО）或 ИП 身份作为**进口商**注册；注册需 УКЭП（合格电子签名） | ✅/◻️ |
| 平行进口 | 进口商（报关主体）负责贴码，无品牌方豁免 | ◻️ [samson.info](https://samson.info/blog/nuzhna-li-markirovka-dlya-parallelnogo-importa-tovarov-v-2026-godu/) 待核 |
| 我方系统角色 | **我方不是系统参与者**——软件以客户（参与主体）的资质与签名调用 ЧЗ 接口；这决定了 API 集成的凭证归属（客户的 УКЭП，❓ 代签机制开发期定） | 🟡 |

### 2.3 码生命周期（赋码到核销的完整链）

```
注册(УКЭП) → ГС1 РУС 入会获取 GTIN ❓ → СУЗ 订码(付费批量)
  → 印贴 DataMatrix（异形面工艺：优先贴包装；滤清器可贴本体；
     橡胶/肋面/玻璃需强胶标签 ✅Kontur）
  → 【进口特规】报关前贴码并在报关单申报（贴标地点=中国仓/保税仓 ◻️Avangard）
  → 入境入库（收货扫码核对，装箱聚合）
  → 销售核销：零售=54-ФЗ 收银→ОФД 自动传 ЧЗ；B2B=УПД 经 ЭДО 传码
  → 退货=重新入转（повторный ввод）
存量缓冲：未码库存可售至 2027-06-01，出转至 2027-11-30，补码至 2028-01-31 ✅Kontur
按件管控：2027-12-01 УПД 按码传输（✅Kontur 草案口径）；2029-05-01 前完成按件过渡（◻️SelSup 口径，两源并记）
```

### 2.4 系统对接面

| 路径 | 用途 | 我方对接方式 |
|---|---|---|
| ЧЗ 开放 API（СУЗ 等） | 订码、入转、出转、退货重入转 | **直连**（四个对接点，§三） |
| ЭДО 运营商（Контур.Диадок/СБИС 等） | B2B УПД 带码传输 | 经运营商 API 或单据导出 |
| 54-ФЗ 收银 + ОФД | 零售核销自动化 | 零售单推收银系统，核销由 ОФД 自动完成 |
| 1С 生态 | 1С:УТ/Розница 内置 ЧЗ 支持 | 并行客户的协同/导出模式（P1） |
| 第三方先例 | SelSup 等已有成品"Маркировка"模块（建卡/GTIN/订码打印/УПД ДОП/出入转） | ✅ 证明独立软件直连是常规路线，无政策障碍 |

### 2.6 系统影响映射 → 《N2 需求规格》草案（v1 范围）

**数据模型增量**：
- 商品（SKU）：`тн_вэд 码`、`is_marked_category`（字典匹配，可扩围）、`GTIN`、`赋码单位（件/箱）`；
- **码实例表**（受控品类专用）：`код（DataMatrix 内容）`、`状态机（订/贴/入转/在库/出转/退回）`、批次、到货单关联、销售单关联；
- 到货（进口批次）：报关单关联 + 码清单导入（ЧЗ 导出文件/Excel）+ 收货扫码核对。

**业务流增量**：
- 收货：受控品类按码扫码入库（码状态→在库）；
- 履约：受控品类拣货**按码实例**出库（扫码确认）→ 零售推收银（ОФД 核销）/ B2B 生成 УПД 码清单（ЭДО）；
- 退货：码状态回转；
- 打印工作台：DataMatrix 标签（GTIN+码），**管理端网页可达——支持从中国远程登录为进口批次打印贴标**（关键场景，§一.5）；
- 报表：在库码数、批次账龄、核销对账。

**API 直连范围（v1）**：订码缓冲、入转（到货确认）、出转（销售确认）、退货重入转——走 ЧЗ 开放 API，测试环境先行；客户 УКЭП 凭证接入方式（本地签名/运营商代签）❓ 开发期定。首客交付允许"导入式"先行（码清单 Excel 进出），API 直连随后——与"规格先行、直连跟上"的裁定一致。

### 2.7 时点话术（销售用）

- **事实**：12 月 1 日起，您进口滤清器/刹车片/火花塞/玻璃/轮毂，**报关前就得贴码**；存量未码货能卖到明年 6 月；
- **我方节奏**：v1（2027 Q1 交付）恰好覆盖"赋码品类的收货—销售—核销"闭环；上游贴标给"远程打印工作台+导入"过渡；
- **一句话**："您的新货 12 月起就要贴码才能报关——我们的系统从订码到核销全程留痕，存量库存帮您算清尾期，罚则 5–30 万卢布起咱就别试了。"
- **风险声明**：现行时限出自 Минпромторг 草案口径，以正式政府令为准——**持续跟踪机制**：每月核查 ЧЗ 官网时令页一次。

## 三、对产品线的三个影响

1. **选品强化**：碰撞件首发线无赋码负担——20号首发品类建议获得合规侧背书；
2. **卖点更新**：赋码从"合规成本"转为**销售话术**——华商第二客的开门话术从"12 月要赋码了怎么办"升级为"12 月起报关前就得贴码，我们系统让您订码、贴标、核销全程留痕"；
3. **工程定位**：N2 从"生死细节"降为**排期项**——增量=数据模型 + 码实例状态机 + 4 个 API 对接点 + 1 个打印工作台，无架构级风险（SKU-B 单体结构不变）。
